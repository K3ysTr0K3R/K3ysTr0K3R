## About

I'm **Jared Brits**, also known as **K3ysTr0K3R**.

I'm a cybersecurity researcher focused on vulnerability research, exploit development, reconnaissance and security tooling.

Most of my work revolves around finding and understanding vulnerabilities in web applications, network appliances, IoT devices and other exposed services, then building proof-of-concept exploits or tools around that research.

I publish my research and projects here on GitHub.
