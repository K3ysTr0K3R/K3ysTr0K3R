# `01` — Identity

> **Breaking software to understand it. Building tools to make security research practical.**

I'm **Jared Brits**, better known online as **K3ysTr0K3R**.

I'm a cybersecurity researcher focused on vulnerability research, proof-of-concept development, reconnaissance, security automation, and practical security tooling.

My work revolves around understanding **why** a vulnerability exists, reproducing its behaviour in a controlled environment, and turning that research into something useful.

```text
RESEARCH
   │
   ├── Vulnerability Discovery
   ├── Root Cause Analysis
   ├── Controlled Reproduction
   ├── PoC Development
   ├── Validation
   └── Documentation
```

> **Understand the weakness. Reproduce the behaviour. Build the tool. Share the knowledge.**

# `03` — Security Arsenal

My GitHub isn't just a collection of PoCs. I also build tools for reconnaissance, enumeration, scanning, and security research.

### `INtrack`

> Internet-scale reconnaissance and vulnerability research tooling.

**INtrack** is designed around crawling the internet for technologies, instances, and potential vulnerabilities.

### `CamTRON`

> Fast camera detection and reconnaissance scanner.

A dedicated project focused on identifying camera and surveillance-related devices during authorized security research.

### `DroidSniper`

> Misconfigured Android Debug Bridge scanner.

DroidSniper detects exposed ADB services and helps identify Android devices where ADB is improperly exposed or configured.
