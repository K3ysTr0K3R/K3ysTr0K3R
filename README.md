About

I'm Jared Brits (K3ysTr0K3R), a cybersecurity researcher and ethical hacker. I focus on vulnerability discovery, exploit development, and security tooling, especially for web applications, network appliances, and IoT devices. My work involves deep analysis of CVEs and exposures, then turning that research into reproducible PoC exploits and practical scanning tools.

    🔍 Vulnerability research & CVE analysis
    💥 Remote Code Execution & exploit development
    🌐 Web, network appliance, and IoT security
    🔧 Tooling: scanners, automation scripts, and reconnaissance frameworks
    🛡️ Authorized security testing and open-source contributions

Featured Projects

    INtrack – Python-based internet reconnaissance & security scanner (multi-threaded, tech detection, CVE scanning).
    Routeglass – Go router/appliance fingerprinting tool (HTTP-based discovery of routers, firewalls, IoT devices).
    CamTRON – Go camera scanner for detecting IP cameras, DVRs, NVRs (multi-brand, concurrent scanning).
    cPanelScanner – Go-based scanner for exposed cPanel/WHM services (CIDR support, multi-threaded).
    MikroTik-Winbox-Scanner – Go scanner for MikroTik RouterOS Winbox (TCP 8291) services, aiding RouterOS security research.
    Ingram (network camera vulnerability scanner) – Research focused on vulnerabilities in Hikvision, Dahua and other camera/DVR infrastructure. (Tool from community)
